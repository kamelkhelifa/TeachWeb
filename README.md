# TeachWeb · الموقع التعليمي

Open physics courseware in **English and Arabic**. Every course is a complete, quality-assured syllabus with the same structure and the same interactive tools.

- **English:** `https://kamelkhelifa.github.io/TeachWeb/`
- **العربية:** `https://kamelkhelifa.github.io/TeachWeb/ar/`
- Personal homepage: [kamelkhelifa.github.io/Home](https://kamelkhelifa.github.io/Home/)

TeachWeb hosts **university-independent open courses**. The courses as taught at each university, with their own syllabi, now live on the personal homepage.
They were moved there from TeachWeb, and the last TeachWeb version that contained them is kept on the `part1-handover` branch.

- Course pages: `/TeachWeb/courses/<slug>/` (Arabic: `/TeachWeb/ar/courses/<slug>/`)
- Course files: `data/open/<slug>.yml`, format in [COURSE_SCHEMA.md](COURSE_SCHEMA.md)

### Publishing a course
The 15 polished courses in `data/open/` are drafts. Only courses with `published: true` at the top of their file appear on the site.
Until the first one is published, the home page shows a "coming soon" state.
To preview every draft locally, run `python build.py --drafts --serve`. Never deploy that build.

## What every course page contains

| # | Section | What's in it |
|---|---------|--------------|
| 1 | Overview | Description, topics at a glance, prerequisites (linked), what it leads to, weekly workload |
| 2 | Learning outcomes | 6–8 CLOs with Bloom level and domain, each mapped to assessments, plus an alignment matrix |
| 3 | Weekly plan | Topics, readings, activities and milestones, with that week's materials. Students tick off weeks to track progress |
| 4 | Assessment | Components and weights, a donut chart and grade calculator (/100 and /20) when weights total 100% |
| 5 | Materials | Notes, slides, problem sets, solutions and videos, filterable by type |
| 6 | Exams | Exam guide, past papers and solutions |
| 7–9 | Worked problems · Self-check quizzes · Interactive lab | Hints and full solutions · instant-feedback quizzes · canvas simulations |
| 10 | Textbooks & resources | Required, recommended and free online resources |
| 11 | Glossary | EN/AR/FR terms with flashcards and pronunciation |

The site also has search (press `/`), light and dark themes, full right-to-left Arabic, print-ready syllabi and phone layouts.
There are no accounts and no tracking. Progress is stored only in the student's own browser.

## Editing content (no coding needed)

- Every text is bilingual: `{ en: …, ar: … }`.
- Maths is LaTeX between `\( … \)` or `\[ … \]`. Put such text in single quotes or a `|` block.
- **Add a PDF:** upload it to `static/files/<course>/` (or use a Drive link) and add an entry under `materials:`. Use `week:` to show it inside that week of the plan.
- **Add a course:** copy a course file next to it, change `slug` (= file name), and edit.
- Interface words are in `data/i18n.yml`, site settings in `data/site.yml`, and the guide page in `data/guide.yml`.

Commit on GitHub (✏️ → *Commit changes*). The site validates, rebuilds and redeploys automatically in about a minute.

## Checking your edits

```bash
pip install -r requirements.txt
python tools/validate.py         # checks every course: bilingual fields, weights sum to 100, quiz answers, LaTeX quoting…
python build.py --serve          # builds to _site/ and serves http://localhost:8000
python build.py --drafts --serve # also shows the unpublished drafts (never deploy this)
```

## Publishing (one-time setup)

1. In the repository: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
2. Push to `main`. The workflow `.github/workflows/pages.yml` validates, builds and deploys.
3. For a custom domain, add a `CNAME` file and update `base_url` in `data/site.yml`.

## Launch switch

`launched: false` in `data/site.yml` keeps the site out of search engines: every page carries
`<meta name="robots" content="noindex, nofollow">` and `robots.txt` disallows all crawlers.
At launch, set it to `true`. The noindex tag is then removed, and `robots.txt` allows crawling and points to the sitemap.

## Technology

Static HTML generated by `build.py` (Python + Jinja2 + YAML). It uses plain CSS and vanilla JavaScript, with no framework.
KaTeX is bundled in `static/vendor/katex` (MIT licence), so maths works without any CDN. Fonts come from Google Fonts.
